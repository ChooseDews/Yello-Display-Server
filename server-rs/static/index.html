The token is saved only on this server in a private file. It is never returned to the browser after saving.

Or sign in with Home Assistant instead. OAuth sends you to your Home Assistant to approve access — no token to paste. The server keeps a refresh token and renews access itself. Saving a token disconnects an OAuth sign-in, and the other way around.

AI

Agent access (MCP)

Let an MCP client list, edit, and preview screen designs directly.

Built in

Endpoint: /mcp (POST, Streamable HTTP / JSON-RPC). Tools: yello_list_designs, yello_get_design, yello_save_design, yello_validate_design, yello_preview_design, yello_list_screens, yello_assign_design, yello_status. Saves are validated like Studio saves and pushed to assigned screens. Like the rest of the Studio API it has no login — keep it on your LAN or tailnet.

Under the hood
A single Rust server renders designs to RGB565 and streams them to the ESP32, which stays a dumb terminal: it draws what it is sent and reports touches back.

      

      
Studio and MCP server in Rust · ESP32 firmware in C on ESP-IDF · browser flashing by ESP Web Tools. Built by John Dews-Flick.
